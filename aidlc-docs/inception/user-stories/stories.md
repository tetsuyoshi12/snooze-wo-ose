# ユーザーストーリー

## MVP ストーリー（ハッカソン必達）

### US-01: アラーム時刻設定
**要件 ID**: F-01

**As a** 慢性的に睡眠不足の社会人（田中健太）  
**I want** アプリで翌朝のアラーム時刻を設定したい  
**So that** 翌朝、AI に二度寝を全力で勧めてもらう準備ができる

**受入基準**:
- 時刻選択 UI で時刻を設定できる
- 設定した時刻がローカルストレージに保存される
- 設定内容が画面に表示される
- アラームの有効/無効を切り替えられる

**優先度**: 必須（MVP）

---

### US-02: アラーム鳴動とスヌーズ
**要件 ID**: F-02

**As a** 朝起きるのが苦手なユーザー（田中健太）  
**I want** 設定時刻にアラームが鳴り、スヌーズ機能を使いたい  
**So that** 段階的に目覚めることができ、急に起きる必要がない

**受入基準**:
- 設定時刻になるとアラームが鳴る
- ブラウザ通知が表示される
- 音声アラートが再生される
- スヌーズ間隔はデフォルト 5 分（設定可能）
- アラーム画面が自動的に表示される

**優先度**: 必須（MVP）

---

### US-03: AI メッセージ生成と表示
**要件 ID**: F-03

**As a** 風情やユーモアを楽しみたいユーザー（山口美咲）  
**I want** アラームが鳴ったときに、AI が詩的・季節的・屁理屈的・共犯的・科学的根拠ベースの言葉で二度寝を勧めてほしい  
**So that** 毎朝違う言葉で楽しみながら、罪悪感なく二度寝を選択できる

**受入基準**:
- 5 つのパターン（詩的、季節、屁理屈、共犯、科学）から 1 つがランダムに選ばれる
- Amazon Bedrock API が呼ばれ、120 字以内の日本語メッセージが生成される
- 生成されたメッセージが墨絵風 UI に表示される
- レスポンスタイムは 5 秒以内
- API 失敗時はフォールバックメッセージが表示される

**技術的制約**:
- Amazon Bedrock（Nova Lite / Claude Haiku / Claude Sonnet）
- `max_tokens: 200` を設定

**優先度**: 必須（MVP）

---

### US-04: 巨大スヌーズ UI（誘惑装置）
**要件 ID**: F-04

**As a** 二度寝を楽しみたいユーザー（田中健太）  
**I want** 画面の大部分を占める「もう少し…」ボタンと、隅に小さい「起きる」ボタンが表示されてほしい  
**So that** 反射的にスヌーズを押しやすく、アプリが積極的に二度寝を誘導してくれる

**受入基準**:
- 「もう少し…」ボタンが画面の 80% 以上を占める
- 「起きる」ボタンは隅に小さく配置されるが、押下可能
- タップ/クリックで適切に反応する
- 墨絵風のデザインが適用される

**優先度**: 必須（MVP）

---

### US-05: スヌーズ記録の保存
**要件 ID**: F-05

**As a** 自分のダメっぷりをエンタメ化したいユーザー（田中健太）  
**I want** スヌーズを押した回数が記録されてほしい  
**So that** 自分がどれだけ二度寝をしているか把握でき、達成感を得られる

**受入基準**:
- スヌーズボタン押下時に回数がカウントされる
- ローカルストレージまたは DynamoDB に保存される
- 記録が永続化され、ブラウザを閉じても保持される

**優先度**: 必須（MVP）

---

### US-06: 堕落ゲージの表示
**要件 ID**: F-06

**As a** 自分のダメっぷりを可視化したいユーザー（田中健太）  
**I want** スヌーズ回数に応じて「堕落ゲージ」が増加してほしい  
**So that** 「立派なダメ人間になりつつある」自分を笑いながら受け入れられる

**受入基準**:
- スヌーズ回数に応じてゲージが視覚的に増加する
- 現在の堕落レベルが表示される
- ゲージが満タンになると特別な演出がある

**優先度**: 必須（MVP）

---

### US-07: 連続二度寝記録の表示
**要件 ID**: F-07

**As a** 継続的に二度寝を楽しみたいユーザー（田中健太）  
**I want** 連続して二度寝をした日数が記録・表示されてほしい  
**So that** 連続記録を伸ばすモチベーションが生まれ、アプリを使い続けたくなる

**受入基準**:
- 毎日スヌーズを押すと連続日数が増加する
- 1 日でもスヌーズしないと連続記録がリセットされる
- 連続日数が画面に「連続 X 日目」と表示される
- 累計スヌーズ時間も表示される

**優先度**: 必須（MVP）

---

### US-08: デモ用ライブモード
**要件 ID**: F-08

**As a** ハッカソン審査員  
**I want** 任意のタイミングでアラーム発火を再現できる機能がほしい  
**So that** 実際の時刻を待たずに、90 秒以内でアプリの全体像を体験できる

**受入基準**:
- 設定画面に「デモ起動」ボタンがある
- ボタンを押すと 5 秒後にアラームが発火する
- デモ用の履歴データ（連続 12 日、堕落ゲージ、称号）が事前に仕込まれている
- デモモードでは実際のアラーム設定に影響しない

**優先度**: 必須（MVP）

---

### US-09: ハッカソンデモシナリオ
**要件 ID**: 要件定義書 3.3

**As a** ハッカソン審査員  
**I want** 90 秒以内で世界観・技術・社会貢献の三層を理解できるデモシナリオを体験したい  
**So that** このアプリの面白さと意義を即座に評価できる

**受入基準**:
- イントロ画面「あなたは、朝起きられますか？」が表示される
- デモ起動ボタンで 5 秒後にアラームが発火
- 雨音と墨絵風 UI が表示される
- AI メッセージが 2 回表示される（詩的パターン + 科学的根拠パターン）
- 記録画面（堕落ゲージ、連続 12 日目、称号「布団仙人」）が表示される
- 30 日達成版の卒業証書が表示される
- 締めのメッセージ「スヌーズを押せ ── これは、押すべきボタンです」

**優先度**: 必須（MVP）

## Nice-to-have ストーリー（時間があれば）

### US-10: 季節・天気連動メッセージ
**要件 ID**: N-01

**As a** 季節の移ろいに敏感なユーザー（山口美咲）  
**I want** 当日の日付や天気に応じた AI メッセージが生成されてほしい  
**So that** より文脈に合った、風情ある言葉で二度寝を勧められる

**受入基準**:
- 当日の日付（季節、二十四節気）を Bedrock プロンプトに渡す
- 天気情報（晴れ、雨、雪など）を取得して反映
- 季節や天気に応じたメッセージが生成される

**優先度**: Nice-to-have

**So that** 段階的な達成感を得られ、アプリを使い続けるモチベーションになる

- 現在の称号が画面に表示される

**優先度**: Nice-to-have

### US-13: 音声読み上げ
**要件 ID**: N-04

**As a** 音声で起こされたいユーザー（山口美咲）  
**I want** AI メッセージが和テイストの声で読み上げられてほしい  
**So that** より没入感のある体験ができ、朝の数分間が特別な時間になる

**受入基準**:
- Amazon Polly で AI メッセージを音声化
- 和テイストの声（落ち着いた女性の声など）を選択
- 音声の再生/停止ができる

**技術的制約**:
- Amazon Polly

**優先度**: Nice-to-have

### US-14: 季節背景画像
**要件 ID**: N-05

**As a** 風情ある体験を求めるユーザー（山口美咲）  
**I want** 時間帯や季節に応じて墨絵風の背景画像が変わってほしい  
**So that** 毎朝違う視覚体験ができ、季節の移ろいを感じられる

**受入基準**:
- Nova Canvas で事前生成した墨絵風背景を複数用意
- 時間帯（朝、昼、夜）や季節（春、夏、秋、冬）で背景が切り替わる
- 背景画像は事前にバッチ生成

**技術的制約**:
- Amazon Nova Canvas

**優先度**: Nice-to-have

### US-15: 雨音 BGM
**要件 ID**: N-06

**As a** 心地よい音で起こされたいユーザー（山口美咲）  
**I want** アラーム鳴動時に雨音などの環境音が流れてほしい  
**So that** 急激に起こされるのではなく、穏やかに目覚められる

**受入基準**:
- アラーム鳴動時に雨音 BGM が自動再生される
- フリー素材の BGM を使用（ライセンス確認済み）
- BGM の音量調整ができる
- BGM のオン/オフを設定できる

**優先度**: Nice-to-have

### US-16: 全国ランキング
**要件 ID**: N-07

**As a** 他のユーザーと競いたいユーザー（田中健太）  
**I want** 連続二度寝記録の全国ランキングを見たい  
**So that** 自分の順位を確認でき、さらに記録を伸ばすモチベーションになる

**受入基準**:
- 連続二度寝記録の匿名ランキングが表示される
- 自分の順位が強調表示される
- ランキングは DynamoDB に保存
- 個人情報は収集しない（匿名）

**技術的制約**:
- Amazon DynamoDB

**優先度**: Nice-to-have

---

### US-17: メッセージ履歴
**要件 ID**: N-08

**As a** 過去のメッセージを振り返りたいユーザー（山口美咲）  
**I want** 過去に表示された AI メッセージの一覧を見たい  
**So that** お気に入りのメッセージを再読でき、多様なパターンがあることを実感できる

**受入基準**:
- 過去に表示されたメッセージの一覧ページがある
- メッセージごとに日時、パターン種別、テキストが表示される
- メッセージに通し番号が付いている（例：「メッセージ #237」）
- 履歴は最新 100 件まで保存

**優先度**: Nice-to-have

## INVEST 基準の確認

すべてのストーリーは以下の INVEST 基準を満たしています：

- **I**ndependent（独立）: 各ストーリーは独立して実装・テスト可能
- **N**egotiable（交渉可能）: 受入基準は調整可能
- **V**aluable（価値がある）: 各ストーリーはユーザーに明確な価値を提供
- **E**stimable（見積もり可能）: 各ストーリーは実装工数を見積もれる粒度
- **S**mall（小さい）: 各ストーリーは 1 つの完結した機能
- **T**estable（テスト可能）: 各ストーリーには明確な受入基準がある
